# Lawrence Maullon Portfolio

A responsive personal portfolio website built for a web developer and aspiring cybersecurity specialist. The site showcases web development projects, cybersecurity learning work, experience, skills, and contact information using a dark modern aesthetic with electric-blue accents.

## Features

- Responsive single-page layout
- Hero section with call-to-actions
- About, skills, experience, resume, and contact sections
- Project filtering for Web Development and Cybersecurity categories
- Mobile-friendly navigation
- Downloadable resume link

## Project Structure


## Local Preview

From the project root, run:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Notes

- The resume file is a placeholder PDF and can be replaced with your final approved resume.
- Update the GitHub, LinkedIn, and email links in the HTML before publishing.
- Project details and contact information can be customized to match your real work and experience.
